本專案移植自 Lee 開源的 NC2000 英雄坛说白金版source code，由 Claude Fable 5 使用 GBDK 2020 製作而成。

1. Menu 增加 速度 欄
   - EXT：與原版相同
   - ADV：打坐 / 練功 / 學習 / 老婆婆任務 等的速度是原版 4 倍，戰鬥訊息速度是原版 2 倍
   - BSC：除繼承 ADV 的改動之外，老婆婆任務以外獲得的報酬，是原版 8 倍

2. 無密碼，存檔有兩個
   - 創建名為 yobdc 的主角時，可開啟作弊菜單（移植自原版輸入 yobdc 密碼時開啟的作弊菜單）

3. 劇情等相比 NC2000 的源代碼，沒有任何改動
   - 女主角的立繪借用了網路圖片

4. EXT ADV 修掉了許多源碼 Bug，但 BSC 保留了下列 Bug
   - 三花 失效後 對方數值被我方數值覆蓋
   - 忍法影分身 用完後 經驗潛能獎勵爆滿
   - 計算回避率時 我方用 根骨 對方用 悟性

5. 逍遙派 新增 凌波微步 及 野球拳
   - 凌波微步 需 跳舞毯 最高分 573
   - 野球拳 為 BSC 限定

6. 支援 GAMEBOY 對戰線連線，但不支援 GBC 紅外線

7. ROM 格式：MBC5 / 32 KiB RAM
   - 不支援 DMG (厚磚 Gameboy)
   - 不支援 MGB (Gameboy Pocket)
