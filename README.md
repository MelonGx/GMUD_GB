本品移植自 Lee 開源的 NC2000 英雄坛说白金版 源代碼，由 Claude Fable 5 使用 GBDK 2020 製作而成。

1. Menu 增加 速度 欄
   - EXT：與原版相同
   - ADV：打坐 / 練功 / 學習 / 老婆婆任務 等的速度是原版 4 倍，戰鬥訊息速度是原版 2 倍
   - BSC：除繼承 ADV 的改動之外，老婆婆任務以外獲得的報酬，是原版 8 倍

2. 無密碼，存檔有兩個
   - 創建名為 yobdc 的主角時，初始經驗 999999，初始潛能 65535，老婆婆任務永遠可以做，獲取菜花寶典不需要幹掉人，其他無變化

3. 劇情等相比 NC2000 的源代碼，沒有任何改動
   - 女主角的立繪借用了網路圖片

4. 支援 GAMEBOY 對戰線連線，但不支援 GBC 紅外線

格式：MBC5 / 32 KiB RAM
- 不支援 DMG (厚磚 Gameboy) / MGB (Gameboy Pocket)
